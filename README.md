# Cute Birthday Surprise Website 💗

## 1. Personalize it
- In `index.html`, replace `My Love!` with her nickname if you decide on one.
- Edit the birthday paragraphs so they sound like you.

## 2. Add photos
Put 1–3 photos in the `photos` folder and name them exactly `photo1.jpg`, `photo2.jpg`, and `photo3.jpg`. If your image is PNG, either convert it to JPG or change the matching filename in `index.html` to `.png`. Photos must be uploaded with the website files so visitors can see them.

**Privacy:** GitHub Pages sites are public. Only use photos you both feel comfortable sharing; avoid intimate or private images.

## 3. Test locally
Double-click `index.html` to open it in a browser. The fonts use Google Fonts and may need an internet connection; the site has fallback fonts.

## 4. Publish free using GitHub Pages
1. Sign in to https://github.com
2. Click **New repository**.
3. Repository name: `birthday-surprise`.
4. Choose **Public** (GitHub Free Pages generally requires a public repository).
5. Click **Create repository**.
6. Click **Add file → Upload files**. Upload `index.html`, `style.css`, `script.js`, and the `photos` folder with any images. Upload the files themselves, not this ZIP.
7. Click **Commit changes**.
8. Open repository **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Choose branch `main` and folder `/(root)`, then click **Save**.
11. Wait a few minutes (sometimes up to 10 minutes), then refresh the Pages settings. Click **Visit site** when the link appears.
12. The URL will look like `https://YOUR-USERNAME.github.io/birthday-surprise/`. Replace `YOUR-USERNAME` with your GitHub username; use the exact URL GitHub shows.
13. Test the link on your phone or in an incognito/private browser, then send the live `https://` link to your girlfriend.

Do not send a local `file:///.../index.html` address; it only works on your computer. GitHub Pages site content is publicly accessible. Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
